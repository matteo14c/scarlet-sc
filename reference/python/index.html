    Python reference¶

    The Python interface: the four commands of the command line, with the same options and defaults, and the model loader. Each option's description is also the command line's help (command-line reference).

    In the source, these descriptions are the docstrings of scarlet/api.py and scarlet/model.py.

    learn ¶

    learn(reference, labels, model, *, technology='auto', blocklist='auto', blocklist_modules='auto', imbalanced='auto', gene_col='index', n_markers=None, marker_shortlist=None, n_iterations=100, n_cells=100, seed=42, ncpu=1, report=False, verbosity='normal')

    Learn a model of the cell types of a labelled reference.

    For each cell type of the reference, SCARLET finds marker genes: genes consistently detected in that cell type and rarely elsewhere. It writes them, with the detection rates it needs to score new cells, to a model file, and writes a plain-language summary of the run next to it. The guide: Learn.

    Parameters:

    Name Type Description Default
    reference str | AnnData

    The labelled reference: an .h5ad file of raw counts (cells x genes); in Python also an AnnData object.

    		 required
    labels str

    The column of the reference's obs that holds the cell-type labels to learn.

    		 required
    model str | None

    The model file to write (.scarlet). In Python, None returns the model without writing it.

    		 required
    technology str

    The technology preset: auto chooses dense when the reference detects at least 5,000 genes per cell on average, else sparse; sparse suits droplet data (e.g. 10x), dense plate data (e.g. Smart-seq2).

    		 'auto'
    blocklist str

    Genes kept out of the markers (technical and stress genes): auto picks the bundled human or mouse list from the gene names; human, mouse, none, or the path of your own tab-separated file with a Symbol and/or ENSG_ID column.

    		 'auto'
    blocklist_modules str

    Advanced. Which gene groups of the bundled lists to apply: auto (a fixed rule on the labels), all, or a comma-separated list of groups. See Advanced options.

    		 'auto'
    imbalanced str

    Unequal class sizes: auto corrects when the largest cell type holds more than a third of the cells, yes always, no never. See Advanced options.

    		 'auto'
    gene_col str

    The var column with the gene names; index uses the var names.

    		 'index'
    n_markers int | None

    Advanced. Markers per cell type; by default the technology preset's (50).

    		 None
    marker_shortlist int | None

    Advanced. The shortlist the markers are ranked on: in each round of the marker search a gene counts towards its stability when it is among the cell type's top marker_shortlist genes; by default the technology preset's (150). Keep it larger than n_markers.

    		 None
    n_iterations int

    Advanced. Rounds of the marker search.

    		 100
    n_cells int

    Advanced. Cells drawn per cell type in each round of the marker search.

    		 100
    seed int

    Random seed; the same inputs, options and seed give the same model.

    		 42
    ncpu int

    Number of CPU cores to use; it does not change the result.

    		 1
    report bool

    Also write the run's HTML report when the model is written (as scarlet report on it).

    		 False
    verbosity str

    What the command prints: normal, its pre-flight once, one progress bar and one line per fold or draw; quiet, nothing; full, everything each step prints. It does not change the result.

    		 'normal'

    Returns:

    Name Type Description
    Model Model

    The learned model (also written to model when a path is given).
    Writes

    model, the model file; <model stem>.summary.txt, the run's summary, next to it; with report, the folder <model stem>_report/ (report.html and its data).

    Raises:

    Type Description
    FileNotFoundError

    The reference, or a blocklist file given by path, does not exist.
    KeyError

    labels is not a column of the reference's obs.
    ValueError

    An option has a value outside its documented ones; with blocklist='auto', the gene names do not tell whether the data are human or mouse; the reference holds negative values (e.g. batch-corrected or scaled data; SCARLET needs counts).

    Examples:

    >>> import scarlet
>>> model = scarlet.learn("reference.h5ad", "cell_type", "reference.scarlet")

    The same from the command line:

    scarlet learn --reference reference.h5ad --labels cell_type --model reference.scarlet

    assign ¶

    assign(model, data, output, *, predictions=None, gene_col='index', alpha=0.01, flip='refuse', save_probs=True, chunk_size=10000, ncpu=1, verbosity='normal')

    Annotate cells with a model.

    Each cell is scored against every cell type of the model and against the background, and receives three calls: the most likely cell type (forced), the best call (unassigned when the background explains the cell as well), and the unique call (unassigned unless the best cell type is clearly better than its competitor). The guide: Assign; the columns: Reading the output.

    Parameters:

    Name Type Description Default
    model str | Model

    The model: a .scarlet file written by learn; in Python also a Model.

    		 required
    data str | AnnData

    The cells to annotate: an .h5ad file of raw counts (cells x genes); in Python also an AnnData object.

    		 required
    output str | None

    The annotated .h5ad to write (the input with the calls in obs). In Python, None returns the calls without writing them.

    		 required
    predictions str | None

    Also write the calls per cell as a tab-separated table to this file.

    		 None
    gene_col str

    The var column with the gene names; index uses the var names.

    		 'index'
    alpha float

    Advanced. The threshold of a unique call: a cell's best call is unique when its adjusted p-value (scarlet_fdr) is below alpha. See Advanced options.

    		 0.01
    flip str

    The flip test, for calls that depend on genes the cell type never showed: refuse (the default) leaves such a cell unassigned, flag keeps the call and marks it in scarlet_flip.

    		 'refuse'
    save_probs bool

    Store each cell's probability for every cell type in the annotated file (obsm['scarlet_probs']).

    		 True
    chunk_size int

    Cells scored at a time; lower it to use less memory. It does not change the result.

    		 10000
    ncpu int

    Number of CPU cores to use; it does not change the result.

    		 1
    verbosity str

    What the command prints: normal, its pre-flight once, one progress bar and one line per fold or draw; quiet, nothing; full, everything each step prints. It does not change the result.

    		 'normal'

    Returns:

    Type Description
    DataFrame

    pandas.DataFrame: One row per cell: scarlet_best, scarlet_unique, is_scarlet_unique, scarlet_fdr and the flags scarlet_flip, scarlet_reason, scarlet_pe_low, scarlet_pe_note.
    Writes

    output, the annotated .h5ad; <output stem>.summary.txt, the run's summary, next to it; predictions, when given.

    Raises:

    Type Description
    FileNotFoundError

    The model or the data file does not exist.
    KeyError

    gene_col is not a column of the data's var.
    ValueError

    An option has a value outside its documented ones; the model file is damaged or was not written by this version of SCARLET; the data hold negative values (SCARLET needs counts).

    Examples:

    >>> import scarlet
>>> calls = scarlet.assign("reference.scarlet", "query.h5ad", "query_annotated.h5ad")

    The same from the command line:

    scarlet assign --model reference.scarlet --data query.h5ad --output query_annotated.h5ad

    transfer ¶

    transfer(reference, labels, query, output, *, origin_col=None, refine=True, depth_match=True, qc=True, technology='auto', blocklist='auto', blocklist_modules='auto', imbalanced='auto', gene_col='index', n_markers=None, marker_shortlist=None, n_iterations=100, n_cells=100, draws=None, seeds=None, alpha=0.01, flip='flag', chunk_size=10000, ncpu=1, report=False, verbosity='normal')

    Transfer the labels of a reference to a query.

    A first pass learns the reference and annotates the query; the refinement then learns again on the query's own stably anchored cells and annotates the query once more. Depth matching first thins the deeper of the two datasets towards the other. The whole transfer is repeated in draws (10 by default), each with its own seed for depth matching and the marker search; a cell's final call is the outcome most draws give, when at least 8 of the 10 draws give it (otherwise the cell is left unassigned: undetermined across draws). With draws=1 (quick mode) the transfer runs once and its calls are that draw's. The transfer check flags cell types whose reference markers the query does not confirm. The guide: Transfer.

    Parameters:

    Name Type Description Default
    reference str | AnnData

    The labelled reference: an .h5ad file of raw counts (cells x genes); in Python also an AnnData object.

    		 required
    labels str

    The column of the reference's obs that holds the cell-type labels.

    		 required
    query str | AnnData

    The cells to annotate: an .h5ad file of raw counts; in Python also an AnnData object.

    		 required
    output str

    The output folder; it is created if it does not exist.

    		 required
    origin_col str | None

    A column of the query's obs naming where each cell comes from (a batch, a technology or a dataset; never the labels). Depth matching, refinement and the transfer check are done per origin.

    		 None
    refine bool

    Refine the first-pass calls on the query's own stably anchored cells.

    		 True
    depth_match bool

    Match the sequencing depth of reference and query before the first pass.

    		 True
    qc bool

    Run the transfer check: per cell type, the share of its reference markers that the query confirms; below 0.2 the cell type is flagged doubtful transfer.

    		 True
    technology str

    The technology preset: auto chooses dense when the shallower of reference and query (after depth matching) detects at least 5,000 genes per cell on average, else sparse.

    		 'auto'
    blocklist str

    Genes kept out of the markers: auto picks the bundled human or mouse list from the gene names; human, mouse, none, or the path of your own tab-separated file.

    		 'auto'
    blocklist_modules str

    Advanced. Which gene groups of the bundled lists to apply: auto, all, or a comma-separated list of groups. See Advanced options.

    		 'auto'
    imbalanced str

    Unequal class sizes: auto corrects when the largest cell type holds more than a third of the cells, yes always, no never.

    		 'auto'
    gene_col str

    The var column with the gene names (in both datasets); index uses the var names.

    		 'index'
    n_markers int | None

    Advanced. Markers per cell type; by default the technology preset's (50).

    		 None
    marker_shortlist int | None

    Advanced. The shortlist the markers are ranked on; by default the technology preset's (150).

    		 None
    n_iterations int

    Advanced. Rounds of the marker search, in each learn of the transfer.

    		 100
    n_cells int

    Advanced. Cells drawn per cell type in each round of the marker search.

    		 100
    draws int | None

    How many times the transfer is repeated, each time with its own seed: by default 10 (accurate mode), or the number of seeds; 1 is quick mode (one draw, no consensus). A final call needs its outcome in at least 80 % of the draws, rounded up (8 of 10). See Advanced options.

    		 None
    seeds list | str | None

    Advanced. The seeds of the draws, one per draw (on the command line separated by commas); by default 1, 2, ... up to draws. The same inputs, options and seeds give the same result.

    		 None
    alpha float

    Advanced. The threshold of a unique call; in a transfer it also selects the stable anchors the refinement learns from. See Advanced options.

    		 0.01
    flip str

    The flip test on the first pass: flag records it per cell and keeps the calls, refuse refuses a flipped cell.

    		 'flag'
    chunk_size int

    Cells scored at a time; lower it to use less memory. It does not change the result.

    		 10000
    ncpu int

    Number of CPU cores to use: the draws run side by side, up to ncpu at a time (faster, with more memory: each draw holds its own copy of the data). It does not change the result.

    		 1
    report bool

    Also write the run's HTML report when the transfer ends.

    		 False
    verbosity str

    What the command prints: normal, its pre-flight once, one progress bar and one line per fold or draw; quiet, nothing; full, everything each step prints. It does not change the result.

    		 'normal'

    Returns:

    Name Type Description
    TransferResult TransferResult

    labels (the final calls per query cell), first_pass (before refinement), qc (the transfer check, or None), reference_models and query_models (the first draw's models, by origin) and record (what was done).
    Writes

    In output: labels.tsv, first_pass.tsv, qc.tsv (with qc), transfer_record.json, summary.txt, the first draw's models reference.scarlet (or reference_<origin>.scarlet) and refine_<origin>.scarlet; with report, the folder report/.

    Raises:

    Type Description
    FileNotFoundError

    The reference or the query file, or a blocklist file given by path, does not exist.
    KeyError

    labels is not a column of the reference's obs, or origin_col of the query's.
    ValueError

    An option has a value outside its documented ones; the species cannot be told from the gene names with blocklist='auto'; an input holds negative values (SCARLET needs counts).

    Examples:

    >>> import scarlet
>>> result = scarlet.transfer("reference.h5ad", "cell_type", "query.h5ad", "transfer_out")
>>> result.labels.head()

    The same from the command line:

    scarlet transfer --reference reference.h5ad --labels cell_type --query query.h5ad --output transfer_out

    report ¶

    report(run, *, reference=None, query=None, model=None, query_labels=None, output=None, self_assessment=True, n_folds=5, seed=0, umap_cells=50000, umap_all_genes=True, alpha=0.01, ncpu=1, verbosity='normal')

    Write the HTML report of a finished run.

    The report reads a run's outputs and changes nothing: a learn report (from a model file) shows the reference, the markers and a cross-validated self-assessment; a transfer report (from a transfer folder) shows the first pass and the refined calls side by side and the transfer check; an assign report (from an annotated .h5ad, with its model) shows the calls and the refusals. Each report also shows the run's summary. The guide: Reports.

    Parameters:

    Name Type Description Default
    run str

    What to report on: a model file (learn), a transfer output folder, or an annotated .h5ad (assign).

    		 required
    reference str | None

    The reference a learn or transfer run used, when its recorded path is no longer readable.

    		 None
    query str | None

    The query a transfer run used, when its recorded path is no longer readable.

    		 None
    model str | None

    The model an assign run used (needed for an assign report).

    		 None
    query_labels str | None

    Transfer and assign reports: an obs column of the query (transfer) or of the annotated data (assign) holding labels you already know for its cells, e.g. in a tutorial. The report then adds a section comparing SCARLET's calls with them (share refused, F1 on the called cells, per label), marked as labels supplied by you; SCARLET never reads them.

    		 None
    output str | None

    The report folder; by default next to the run (<stem>_report/, or report/ in a transfer folder).

    		 None
    self_assessment bool

    Learn and transfer reports: estimate how well the model calls its own reference, by cross-validation (it learns once per fold, so it takes longer).

    		 True
    n_folds int

    Folds of the self-assessment.

    		 5
    seed int

    Seed of the self-assessment's folds and of the UMAP layout.

    		 0
    umap_cells int

    At most this many cells in the report's UMAP plots.

    		 50000
    umap_all_genes bool

    Also compute each UMAP on all genes, a second space the reader can switch to (the place to look for populations the model lacks); the default space is the model's own genes. No skips it (faster on very large data); the report then says so.

    		 True
    alpha float

    Advanced. The threshold of a unique call in the learn report's self-assessment. An assign report uses the alpha the assign run recorded (a different value given here is an error).

    		 0.01
    ncpu int

    Number of CPU cores to use; it does not change the result.

    		 1
    verbosity str

    What the command prints: normal, its pre-flight once, one progress bar and one line per fold or draw; quiet, nothing; full, everything each step prints. It does not change the result.

    		 'normal'

    Returns:

    Name Type Description
    str str

    The path of report.html.
    Writes

    The report folder: report.html (one self-contained page) and bundle/ (its tables and data); a transfer report also writes refinement.html (what refinement changed, linked from its section 6) and supplement_A/ (the report of the reference model).

    Raises:

    Type Description
    ValueError

    run is not a finished SCARLET run; an input the report needs (the reference or the query) cannot be read from its recorded path and was not given; an assign report without its model, or with a model the data were not annotated with.

    Examples:

    >>> import scarlet
>>> scarlet.report("reference.scarlet")

    The same from the command line:

    scarlet report reference.scarlet

    Model dataclass ¶

    A learned SCARLET model, as learn returns it and load_model reads it from a model file.

    A model file is a zip archive of members (tables and records). files holds each member's bytes; the properties below read them. See Reading the output for what each member holds.

    Attributes:

    Name Type Description
    files dict

    Member name -> bytes.
    path str | None

    The file the model was read from or saved to, if any.

    Examples:

    >>> import scarlet
>>> m = scarlet.load_model("reference.scarlet")
>>> m.identities
>>> m.markers.head()

    markers property ¶

    markers

    The markers of every cell type, ranked (markers.tsv).

    universe property ¶

    universe

    Per marker gene, its detection rate in every cell type and in the background (universe.tsv).

    in_class property ¶

    in_class

    Every gene the marker search scored (after the blocklist) x each identity: the share of the identity's cells detecting it, the bootstrap estimate the universe holds for the markers, with the background column bg (the universe is this table's marker rows). None for a model without it (written before 0.6.3).

    background property ¶

    background

    The detection rate of every gene across the reference (background_universe.tsv), or None.

    programmes property ¶

    programmes

    Cell type -> its marker genes, in rank order (programmes.json).

    identities property ¶

    identities

    The model's cell types (its identities), in the order of the model.

    settings property ¶

    settings

    The command that learned the model, the settings it used and its options (settings.json).

    provenance property ¶

    provenance

    When and with which versions the model was learned, and from which input (provenance.json).

    marker_finder_params property ¶

    marker_finder_params

    Every setting of the marker search as used (marker_finder_params.json).

    extract ¶

    extract(member, dest)

    Write one member of the model file, byte for byte, to dest; returns its path.

    save ¶

    save(path)

    Write the model file to path (a zip archive with a manifest of checksums); returns its path.
